# AIOps Scenario Guides

Use these labs after the basic EC2 + CloudWatch deployment is working.

Recommended order:

```text
1. Baseline monitoring
2. Static SNS request-volume alerts
3. Latency anomaly
4. Error spike
5. Worker bottleneck
6. Queue backlog
7. Log anomaly and incident summary
```

The `/aiops` page provides buttons for activating scenarios. The scripts provide the same controls from terminal.
